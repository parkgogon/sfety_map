## 운영 전송 금지

- 이 개선의 자동 테스트·브라우저 검수에서 실제 Telegram·SMS를 보내지 않는다.
- 사용자/관리자 운영방, 운영 Worker 시험·dispatch 경로와 운영 수동전파 API를 호출하지 않는다.
- 발송은 가짜 제공자와 메모리 저장소로 검증한다. 브라우저 전파 검수도 가짜 API에서만 수행한다.
- Python 공통 테스트 실행기는 수집 전부터 실제 HTTP·TCP를 막고, 코드가 차단 예외를 처리해도
  통신 시도 자체가 있으면 검증을 실패시킨다. 프런트엔드도 실제 HTTP 시도를 실패시킨다.
- 운영 snapshot·자동알림 기준 상태·실적을 변경하지 않는다. 이 작업은 커밋·push·배포를 포함하지 않는다.

  `test_manual_scope_rejects_stale_or_error_snapshot` 1개다.
- 따라서 기존 시나리오를 정상적인 TestCase 메서드로 정리한 기준 수는 259개이며,
  발송 차단 보호장치의 회귀 테스트는 별도로 추가한다.
