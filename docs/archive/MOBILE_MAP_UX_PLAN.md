## 2. 목표와 변경 범위

모바일에서 지도가 주인공이 되게 한다. 기본 화면에는 작은 통합 헤더,
검색 진입 버튼 하나, 지도와 최소한의 지도 조작 버튼만 둔다.
검색 결과·설정·시설 상세를 쌓지 않고 주요 작업 패널은 한 번에 하나만 표시한다.

- 현장 지도 `/`의 너비 700px 이하만 개편한다.
- 너비 701px 이상 PC 현장 지도와 `/control`, `/settings`의 기존 배치를 유지한다.
- 애플리케이션 수정은 `field_web/`, 관련 계획·검수·사용 흐름·handoff 문서 갱신은 허용한다.
- 서버 API·시설 데이터·위험도·자동알림·전파 대상·PDF는 변경하지 않는다.
- 새 UI 라이브러리·아이콘 패키지·지도 SDK를 추가하지 않는다.
- 위치 권한·내 위치 추적·사고 이력 저장·PWA 설치 기능은 추가하지 않는다.
- 기존 미추적 문서·mockups·시설 원본은 수정·삭제·커밋하지 않는다.

유지할 기능:
- 전체 시설 검색과 검색 선택 시 필요한 유형·등급 필터 자동 완화
- 시설 ID 선택·`facility_id` 딥링크, 유형·위험등급 필터
- 시설 아이콘·같은 좌표 시설 목록·클러스터
- 특보 구역·기상 레이어
- 장소·주소 검색·지도 직접 지정·확인 후 기준점 확정
- 거리 원·전체 시설 거리순 목록·연결선·직선거리
- 실시간·모의훈련, 수신 지연·조회 불가 구분, 중앙관제 기존 동작

## 3. 화면별 최종 모습

### 3.1 기본 화면

```text
현장 안전지도                        더보기
● KMA 정상 · 12:55 기준
[ 시설·장소·주소 검색 ]

                  지도
                                  [＋]
                                  [－]
[전체 시설]                   [지도 설정]
```

모바일 상시 위험등급 범례, 선택 전 빈 시설 안내 카드, 검색 모드 행,
별도 필터·기상 진입 버튼은 제거한다. 기능은 검색 패널·지도 설정으로 옮긴다.

### 3.2 통합 헤더

- 제목 `현장 안전지도`, 둘째 줄 자료 상태·기준 시각, 우측 더보기.
- 모바일 영어 브랜드는 제거. 기존 토큰의 흰 표면·남색 텍스트 사용.
- 기본 64~72px 목표, 제목 18px, 상태 12~13px. 큰 글자에서는 높이를 늘린다.
- 제목·상태 전체를 큰 터치 영역으로 하여 자료 상태 패널을 연다.
- 오늘은 HH:mm 기준, 다른 날은 날짜 포함. 상태 패널에는 전체 날짜·시각.
- LIVE `KMA 정상`, STALE `KMA 수신 지연`, 자료 사용 불가 `KMA 조회 불가`,
  SIMULATION `모의훈련 · 실제 상황 아님`. 자료 수신 정상을 시설 안전으로 해석하지 않는다.
- STALE: 헤더 아래 `수신 지연 · 마지막 정상 자료 표시 중`.
- 자료 사용 불가: `특보 조회 불가 · 시설 위치만 확인 가능`.
- 상세 원인·마지막 정상 시각은 상태 패널. 상태를 숨겨 공간을 확보하지 않는다.
- 기존 모의훈련 안내·실시간 복귀 유지.
- 경계 자료 대체 등 부가 안내는 상태 패널, 헤더에 추가 안내 존재 표시.
- 잘못된 시설 딥링크 등 행동 관련 안내는 행동 직후 확인 가능하게 유지.

### 3.3 더보기

중앙관제 열기 / 관제 자료 새로고침 / 기상청 특보 보기 /
모의훈련 화면 보기 또는 실시간 화면으로 돌아가기를 제공한다.
기존 함수·모드 전달·외부 링크 보안 속성을 재사용하고 새로고침 중 중복 실행을 막는다.
모바일 모의훈련 진입은 기존 시설 필터에서 더보기로 이동한다.

### 3.4 검색 패널

검색 진입을 누르면 제목·닫기, 우리 시설/장소·주소 선택, 입력, 결과 순으로 표시한다.

우리 시설:
- 최초 기본 모드. 기존 전체 시설 검색, 지도 필터와 무관하게 검색.
- 선택 시 검색 패널을 닫고 시설 요약. 필요한 유형·등급만 자동 활성화.
- 기존 URL·지도 이동 유지.

장소·주소:
- 기존 검색 함수를 사용하고 검색 버튼/Enter로 실행, 직접 지정 제공.
- 로딩·빈 결과·일부/전체 실패·늦은 응답 무시 유지.
- 결과 클릭만으로 기준점 확정 금지.

선택 없이 닫으면 이전 지도로 돌아가고 기준점·시설 선택을 삭제하지 않는다.
검색어·모드는 페이지 안에서 유지한다. 늦은 검색 응답은 닫힌 패널을 열거나
기준점을 변경하지 못한다.

### 3.5 후보 확인

검색 결과 선택 후 키보드·검색 입력·결과 목록을 닫고 후보 핀과 작은 하단 확인만 표시한다.
이름·주소/좌표·대표 위치 주의, 다시 찾기·이곳으로 지정·취소를 제공한다.
직접 지정이면 위치 다시 지정도 제공한다. 이름 수정은 버튼을 눌러 편집한다.
지도 이동·확대는 가능하지만 마커 클릭으로 시설 상세가 갑자기 열리지 않게 한다.
확정·취소는 스크롤 밖에 고정하고 취소 시 이전 확정 기준점을 복원한다.

### 3.6 지도 직접 지정

검색 패널을 닫고 위치 지정 안내·취소만 표시한다.
빈 지도·시설 마커·특보 구역 클릭을 위치 지정으로 처리하고 후보 확인으로 전환한다.
클릭 즉시 확정하지 않는다. 이때 시설 상세·기상 정보 카드는 새로 열리지 않는다.

### 3.7 확정 기준점·주변 시설

검색 입구 아래 `[이름 · 기준점 / 주변 시설 / 삭제]` 한 줄 요약.
긴 이름은 말줄임, 주변 패널에서 전체 이름을 확인한다.
삭제는 기준점·거리 원·연결선만 지운다.
전체 시설 거리순, 숨긴 시설 안내·선택 복구, 10개씩 더 보기, 5km 이내 개수 유지.
거리 원 토글·기준점 보기·이름/위치 수정은 주변 패널에서 제공한다.
시설 선택 시 목록 대신 시설 요약. 피해·위험 판정이 아닌 거리 참고 설명 유지.

### 3.8 지도 설정

시설 / 기상 / 범례 세 탭. 패널은 하단에 표시한다.

시설 탭:
- 기존 그룹 아이콘·명칭·전체 개수·체크박스와 위험등급 6종 다중 체크박스.
- 위험등급 순서: 상/중/하/영향 없음/미판정/조회 불가.
- 단일 드롭다운으로 단순화 금지. 변경은 즉시 반영.
- 전체 표시는 유형·등급 모두 초기화.
- 하단 `현재 N개 / 전체 M개 표시`와 지도 보기.
- 그룹 개수는 전체 자료 기준임을 유지. 모두 해제 허용, 0개 복구 제공.
- 패널 밖에도 `필터 적용 · N개 표시` 표시.
- 갱신 시 기존 그룹의 사용자 선택 유지, 처음에만 전체 선택,
  새로 등장한 그룹만 기본 추가, 삭제된 그룹 ID 정리.
  기존 코드의 갱신 때 해제 그룹을 다시 추가하는 동작을 바로잡는다.

기상 탭:
- 끄기/강수/바람/기온 단일 선택, 모의훈련 추천 유지.
- 즉시 반영하되 지도 보기로 닫는다.
- 활성 자료 명칭·작은 색상 눈금·단위·관측 시각은 지도에서 보인다.
- 상세 설명은 패널, 지연·오류·훈련값 구분은 지도에서도 유지.
- 비활성일 때 빈 기상 범례 공간을 만들지 않는다.

범례 탭:
- 읽기 전용. 필터나 위험등급 토글을 넣지 않는다.
- 시설 유형 아이콘·명칭, 시설 마커 등급 색상·설명, 특보 경보·주의보 색상·설명.
- 기존 등급 순서·설명 재사용, 색상과 글자를 함께 제공.

### 3.9 시설 상세

선택 시에만 표시. 접힘: 등급·시설명·영향 특보·권장 행동 요약·자세히·닫기.
기상·주소·담당·특보 근거·참고정보는 펼침에서 제공한다.
새 시설 선택 시 접힘, 이름 최대 2줄, 여러 특보는 요약+추가 개수와 펼침 전체 정보.
권장 행동 제거 금지. 접힘 160~200px 목표, 작은 화면에서는 지도 높이 최대 36%.
제목·닫기·펼치기는 조작 가능하게 고정하고 넘친 본문만 스크롤.
펼침에서는 넓게 읽되 간단히·닫기 제공. 새 드래그 제스처/라이브러리 도입 금지.
시설 닫기는 선택·URL을 정리하고 확정 기준점을 유지한다.

## 4. 패널 전환·레이아웃·지도 동작

### 4.1 단일 패널

검색/설정/자료 상태/더보기/후보 확인/주변 시설/같은 좌표 목록/시설 상세를 겹쳐 열지 않는다.
독립 open boolean을 계속 추가하지 않고 모바일 패널 상태를 한 곳에서 관리한다.

```ts
type MobilePanel = "none" | "search" | "map-settings" | "status" | "more"
  | "nearby" | "same-location" | "facility";
type MobileSettingsTab = "facilities" | "weather" | "legend";
type MobileSearchTab = "facilities" | "location";
```

좌표·picking/candidate/point는 기존 기준점 상태만 사용한다.
직접 지정 → 후보 확인 → 일반 패널 순으로 표시한다.
미확정 작업 도중 다른 작업을 명시적으로 열면 미확정만 취소하고 확정 기준점은 유지.
일반 패널은 시설 선택을 삭제하지 않고 닫으면 요약으로 돌아온다.
후보 취소는 이전 확정 기준점 또는 검색 화면 복귀.
Escape는 현재 작업 하나만 닫고 시설 선택까지 연속 삭제하지 않는다.

### 4.2 모달 구분

검색·설정·상태·더보기·전체 목록은 모달: 배경 차단·포커스 이동/복원·제한·Escape.
후보 확인·접힌 시설 요약은 지도 조작 가능, 직접 지정은 안내만 표시.
지도 조작이 필요한 패널에 전체 클릭 차단막을 두지 않는다.

### 4.3 크기·스타일

검색 입구 48px·가장자리 12px, 터치 44×44px 이상, 입력 16px 이상,
본문 15px, 보조 12~13px, 버튼/입력 반경 12px·패널 위 반경 20px,
간격 4px 단위·아이콘 18~20px 선형으로 통일.
기존 위험색·시설 아이콘 유지. 과한 그림자·테두리·이모지 버튼 추가 금지.
큰 글자에서는 고정 높이로 자르지 않는다.

### 4.4 높이·키보드

검색·설정·목록 최대 가용 높이 70%, 제목/닫기/주요 버튼 고정·본문만 스크롤.
키보드 표시 시 결과 영역 축소, 선택 후 포커스 해제.
100dvh와 safe-area 적용, 모바일 최소 높이 540px 해제.
가로 화면·큰 글자는 세로 공간·본문 스크롤로 대응, 페이지 가로 넘침 금지.

### 4.5 지도 버튼

좌하단 전체 시설, 우하단 지도 설정, 그 위 작은 +/-.
Kakao 로고·축척을 덮지 않는다. 하단 작업 패널이 열리면 기본 하단 버튼은 숨긴다.
기상 눈금은 기본 버튼 또는 지도 조작용 패널 위에 실제 높이 반영하여 배치.
전체 시설: 유형/등급 전체 복구 → 시설 선택/비교 대상 정리 → 전체 시설 범위 맞춤.
확정 기준점·기상 선택 유지. 갱신·목록·기상 전환으로 자동 전체 맞춤 금지.

### 4.6 지도 이동

검색 입구·기준점 요약·기상 눈금·패널 실제 크기로 가림 영역 측정.
시설 마커·후보 핀·접힌 거리 비교의 두 지점/거리 배지 노출 보장.
펼친 상세에서는 억지 맞춤 불필요, 접으면 다시 보정.
ResizeObserver 감지·정리, 지도 드래그만으로 맞춤 재실행 금지.
모바일/PC 전환으로 지도 재생성 금지. 이동 요청은 한 경로, 최근 사용자 요청 우선.
폭 전환 시 SDK 컨트롤 갱신, 모바일의 긴 SDK 막대와 새 +/- 중복 표시 금지.

외부 API/응답 타입 변경 없음. 내부 모바일 패널·탭 타입, matchMedia 훅,

공유 prop은 생략 시 기존 동작. 중앙관제에 모바일 하단 패널을 적용하지 않는다.
공유 전역 CSS 덮어쓰기 금지, 현장 지도 모바일 클래스에 제한한다.
같은 선택자를 계속 추가하는 우선순위 패치 금지.
