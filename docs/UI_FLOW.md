# UI 정보 구조와 사용자 흐름

- 문서 상태: v3 구현 기준
- 대상 버전: v3

## 1. UI 목표

사용자는 역할에 맞는 페이지에서 다음 순서로 작업합니다.

```text
시설 담당자: 현장 지도 → 시설 검색·마커 선택 → 특보·현재 기상 확인 → 필요 시 기상 레이어·CCTV 조회
중앙 관제: 운영 상황 → 대상 분석·전파 → 실적·이력
설정: 위험도 행렬 편집 → 현재 세션에 적용 또는 기본 기준 복원
```

발송과 보고서가 별도 범위를 다시 선택하지 않으며, 체크박스 표가 두 출력물의
유일한 대상 기준입니다.

## 2. 정보 배치

| 정보 | 표시 위치 | 원칙 |
|---|---|---|
| 상단 메뉴 | 모든 페이지 상단 | 모바일에서도 현장 지도·중앙 관제·설정을 한 줄로 표시 |
| 현장 시설·특보 | 현장 지도의 팝업과 하단 카드 | 시설 ID로 선택하고 전체 시설 중 영향 시설을 강조 |
| 현재 기상·CCTV | 선택 시설 카드 아래 | 기상은 자동, CCTV는 사용자 요청 후 조회 |
| 기상 그래픽 레이어 | React 현장 지도·중앙관제 지도 | 기본 꺼짐, 강수·바람·기온 중 하나만 표시 |
| 중앙관제 현황 | `운영 상황` | 전체·영향을 우선 표시하고 등급은 비조작형 한 줄 요약으로 표시 |
| 수동 전파 대상 | `대상 분석·전파` 목록 | 수동 Telegram의 유일한 대상 기준 |
| 위험도 기준 | 설정 페이지 | 전체 특보 행렬, 현재 세션에만 적용 |

## 3. 기본 화면

```text
[현장 지도] [중앙 관제] [설정]

현장 지도: KMA 상태 → 유형·검색 → 대형 지도 → 선택 시설·현장정보
중앙 관제 기본: 운영 경로 상태 → 전체·영향 현황 → 등급 요약 → 우선순위·소형 지도
중앙 관제 분석: 선택 현황 → 빠른 선택 → PDF·수동 전파 → 대상 목록·지도
설정: 기본·현재 정책 버전 → 전체 위험도 행렬/모바일 카드 → 적용·복원
```

시설 유형 기본 그룹은 대기측정소, 수질측정소, 영농폐기물 수거사업소,
영농폐비닐 재활용시설, 공공하수처리시설, 기타시설입니다. 그룹에 등록되지 않은
신규 시설 유형은 기타시설에 자동 포함됩니다.

## 4. 선택과 출력 규칙

1. 현장 지도와 중앙관제의 필터·선택 상태는 서로 분리합니다.
2. 현장 지도는 전체 시설 유형과 전체 등급을 기본 표시하고, 시설 유형은 즉시
   적용하며 등급은 지도 내부 제어에서 서버 재실행 없이 표시·숨김 처리합니다.
3. 시설 마커 선택은 좌표가 아니라 시설 ID를 사용합니다.
4. 단일 마커는 현재 지도 배율을 유지하고 중앙으로만 이동합니다. 숫자
   클러스터는 확대하고, 검색·딥링크는 시설로 이동·확대합니다.
5. 현재 기상은 선택 250ms 후 자동 조회하고 CCTV는 요청한 뒤에만 조회하며,
   위험도·Telegram·PDF에는 반영하지 않습니다.
6. 기상 그래픽은 사용자가 레이어를 켰을 때만 조회하고 10분 단위로
   갱신합니다.
   - 모의훈련 진입 시 특보 기반 추천 레이어(태풍/강풍→바람, 호우/대설→강수, 폭염/한파→기온)를 snapshot 도착 시 1회 자동 선택하고, 사용자가 수동 선택한 이후에는 덮어쓰지 않으며, 실시간 복귀 시 훈련 레이어를 정리합니다.
   - 훈련 compact 범례는 `레이어명 · 훈련값` 수준으로 간결화하고, 중앙관제 복귀 동작은 상단 보라색 배너 1곳으로 단일화합니다. 스크린리더 레이블과 레이어 선택 시트에는 안전 가이드 문구를 보존합니다.
   - 기온·강수 레이어는 화면 공간의 가까운 유효 기상점 최대 4개를 거리 제곱
     역가중치로 보간한 연속 raster를 사용합니다. 최종 alpha는 기온 0.24,
     강수 0.28이며 관측점에서 인접 격자 간격 0.9~1.75배 구간은 부드럽게
     투명화합니다. 강수 0mm도 경계 보간에 포함하되 최종 0.1mm 미만은
     표시하지 않습니다.
   - 기상 canvas는 viewport 밖에 128~256px overscan을 두고 panning 시작 좌표의
     화면 이동량을 animation frame당 한 번 반영합니다. 이동 중 그래픽을 숨기지
     않고 `idle`에서 현재 중심으로 다시 투영한 뒤 transform을 초기화합니다.
     zoom 중에는 잠시 숨기고 좌표 축척이 확정된 `idle`에서 다시 표시합니다.
   - 바람 레이어는 최근접 유효점 최대 4개의 `u_ms`·`v_ms`를 IDW 보간한 12px
     vector field를 기반으로 저채도 푸른 연속 풍속 색면(alpha 0.14, 회청색→남색 `0~25m/s+`)과
     중립색 파티클을 함께 표시합니다. 범례에는 `0~25m/s+` 수치 단계와 `입자 방향=풍향, 이동 속도·꼬리=풍속`을
     명시합니다.
   - 기상 레이어가 켜져 있을 때 빈 지도 지점을 누르면 해당 위치의 `선택 지점 보간값`
     (기온·강수 소수점 1자리 수치, 풍속 m/s 및 8방위 흐름 각도, 기준 시각, 실황/지연/훈련 구분)을
     공용 `MapInformationCard`로 표시합니다.
   - 특보 영역(Polygon)을 누르면 해당 구역명과 발효 중인 모든 특보(종류·단계·발효 시각,
     모의훈련 시나리오 가정 문구)를 `MapInformationCard`로 표시합니다. 특보 터치는 지도 지점
     기상값 조회보다 우선하며 시설·클러스터 터치와 충돌하지 않습니다.
   - 중앙관제 헤더에는 현재 반영된 웹 번들의 Git SHA(7자리)와 KST 배포 시각을
     작은 뱃지(`.build-info-label`)로 표시합니다.
   - 바람 animation은 viewport 면적 기준 120~600개, 약 30fps, 2~38px/s와
     delta-time 상한을 사용합니다. panning 중 계속 흐르고 `idle`에서 field와
     particle을 재생성하며 zoom·탭 비활성·레이어 전환·화면 종료 시 안전하게
     중지·재개합니다. reduced-motion은 중립색 정적 흐름선으로 대체합니다.
   - 미선택 단일 시설은 등급과 관계없이 30px로 표시하고 색상으로 구분합니다.
     같은 좌표 숫자 마커 34px, 선택 시설 44px, 일반 클러스터 38px를 사용하며
     지도 레벨 8부터 개별 시설을 표시합니다. 마커·클러스터는 기상 canvas보다
     위에 배치하고 시설 위치의 기상 그래픽을 원형으로 지우지 않습니다.
   - 선택 시설의 현재 기상은 실황 참고정보로 독립 유지합니다.
7. 중앙관제 우선순위의 등급·시설 유형·검색은 목록 조회용이며 자동으로
   후속 작업 대상을 바꾸지 않습니다.
8. `대상 분석·전파`의 특보 영향·전체·해제 버튼과 개별 체크박스만 확정
   대상을 바꿉니다.
9. 영향 시설이 있으면 기본 전체 선택하고, 없으면 전체 시설을 선택합니다.
10. 데스크톱은 표, 모바일은 `체크박스·등급·시설·특보` 중심 카드로 같은
    선택 상태를 편집합니다.
11. 수동 Telegram은 체크된 시설 및 해당 시설의 연결 특보만 받습니다.
12. PDF는 체크 상태와 무관하게 전체 103개 소관시설의 종합 관제 snapshot을
    사용합니다. 모드·KMA 결과·정책이 바뀌면 새 자료 기준으로 다시 생성합니다.
13. 선택 대상이 0개인 작업을 제출하면 안내만 표시하고 작업창을 열지
    않습니다. KMA 조회 실패 시에는 Telegram과 PDF 버튼을 비활성화합니다.
14. 시설 상세 정보와 후속 작업 대상은 PC·모바일 모두 기본으로 접고,
    펼치거나 접는 동작만으로 현재 시설·작업 대상 선택은 변경하지 않습니다.

## 5. 작업창

### 시설담당자 그룹 수동 전파

- 선택 시설 수, 연결 특보 수, 상 위험 수를 먼저 표시합니다.
- 상황 요약 1건 뒤에 `상 → 미판정 → 중 → 하` 상세를 전체 표시합니다.
- `재공지·정정·추가안내·훈련`으로 분류하고 수동 상황전파임을 명시합니다.
- 유효한 HTTPS 운영 주소가 있으면 시설명을 `facility_id` 딥링크로 표시합니다.
- 대상·메모·미리보기를 확인하고, 중복·훈련·임시 정책은 추가 확인 후에만 발송합니다.
- 임시 위험도 기준을 사용하면 메시지에 명시합니다.
- 발송 결과는 현재 화면에만 표시하고 저장하지 않습니다.

### PDF

- 전체 103개 소관시설의 종합 관제 snapshot을 사용하며 선택 체크박스와 독립입니다.
- 헤더에 조회 범위, 실시간·모의훈련·임시정책 배지, 생성 시각과 정책 버전을
  표시합니다.
- `관제 요약 → 영향시설 우선순위 → 활성 특보` 순으로 구성합니다.
- 남색 헤더, 청록 강조선, KPI 카드와 등급 색상을 업무 식별에만 사용합니다.
- KMA 자료가 `LIVE` 또는 `SIMULATION`이 아니면 신규 생성을 차단합니다.

## 6. 위험도 기준 편집

- 정책에 등록된 전체 특보를 행으로, 주의보·경보·중대를 열로 표시합니다.
- 700px 이하에서는 각 특보를 카드로 바꾸고 같은 3단계 선택칸을 한 줄에
  표시합니다. 내부 API 등급 값은 바꾸지 않습니다.
- 현재 발효 중인 특보를 상단에 놓고 빨간 상태점과 `발효 중`을 표시합니다.
- 미등록 활성 특보도 임시 등급을 지정할 수 있습니다.
- 설정 페이지의 셀 변경은 재실행하지 않고 `현재 세션에 적용`을 누를 때 전체 위험도를
  한 번 재계산합니다.
- 기본 파일·DB·다른 브라우저에 저장하지 않습니다.

## 7. 예외와 반응형 화면

- API 오류 시 지표는 0이 아닌 `—`로 표시하고 후속 작업을 차단합니다.
- 경계 내장본 사용 시 계산은 계속하되 상태 안내를 표시합니다.
- 미판정 특보는 낮은 위험으로 바꾸지 않고 별도 등급으로 유지합니다.
- 모의훈련은 상태 표시, Telegram과 PDF 제목에 모두 명시합니다.
- 모바일 헤더는 영문 브랜드를 숨기고 현재 화면 제목과 필수 이동 버튼만 유지합니다.
- 현장 지도는 이동·확대를 기본 활성화하고 지도 내부 버튼으로
  페이지 스크롤 우선 모드로 바꿉니다.
- 현장 범례는 모바일에서 `위험등급 1행 + 특보구역 1행`으로 표시하고 접힘 상태를
  선택·상세 변경 후에도 유지합니다.
- 운영 상황은 `전체·영향` 2개를 우선 표시하고 `상·중·하·영향 없음`을 한 줄로
  압축하며 이 요약은 버튼이 아닙니다.
- 대상 분석·전파는 `선택 현황 → 빠른 선택 → PDF·수동 전파 → 목록 → 지도` 순서로
  표시하고 모바일 지도는 370px로 제한합니다.
- 위험도 정책은 데스크톱 행렬표와 모바일 특보 카드를 각각 사용하고, 적용·복원
  버튼은 모바일에서 44px 이상 두 열로 배치합니다.

## 8. 접근성과 안전성

- 등급은 색상과 텍스트를 함께 사용합니다.
- 바람은 범례 텍스트로 입자 방향·속도·꼬리의 의미를 제공하고 reduced-motion에서도
  정적 흐름선으로 풍향 정보를 유지합니다.
- 필터와 체크박스는 키보드로 조작할 수 있어야 합니다.
- 최종 선택 대상 수와 연결 특보 수는 수동 Telegram 작업창에서 확인합니다.
- 담당은 부서·이름/직책만 표시하며 휴대전화는 화면·Telegram·PDF에 노출하지 않습니다.
- 수동 Telegram은 시설담당자 그룹으로만 보내며 `재공지·정정·추가안내·훈련`을
  명시합니다. 정정·추가안내 메모, 훈련 이중 확인, 최근 30분 중복 확인을
  거친 요청만 관리자 API가 접수합니다.

## 9. 현장 참고정보

- 선택 시설 20km 내 ITS 고속도로·국도 CCTV를 직선거리 순으로 최대 5개 표시합니다.
- CCTV 플래그가 비활성인 배포에서는 버튼·마커·영상 작업창을 렌더링하지 않고
  서버도 ITS를 호출하지 않습니다.
- CCTV 마커를 누르면 중간 말풍선 없이 큰 영상 작업창을 열고
  내장 재생·외부 영상·ITS 지도 링크를 제공합니다.
- ITS가 촬영 방위각을 제공하지 않으므로 방향을 자동 추정하지 않습니다.
  이름·좌표가 일치하는 사람 검증 설정이 있는 CCTV만 지도에 고정 방향
  화살표를 표시하고, 나머지는 `촬영방향 미확인`으로 표시합니다.
- 영상 파일 생성 시각과 ITS 영상 주소 조회 시각을 구분하고, 생성 시각이
  제공되지 않으면 촬영 시각을 확인할 수 없음을 명시합니다.
- CCTV 정보는 최대 1분 캐시하며 1분 후 `최신 정보 다시 조회`를
  사용할 수 있습니다. ITS가 같은 URL을 반환하면 같은 영상이 보일 수 있으며
  재생 중인 영상은 자동으로 교체하지 않습니다.
- 선택 시설 관할의 최근 6시간 재난문자를 최대 5건 원문으로 표시합니다.
- API 미설정·오류·0건을 구분하고 KMA 관제와 후속 작업은 차단하지 않습니다.
- 뉴스는 관할·특보 검색어를 사용한 외부 최신순 링크만 제공합니다.
- CCTV·재난문자·뉴스는 참고용이며 위험도·Telegram·PDF에 반영하지 않습니다.
- Google 뉴스 검색 기준과 참고정보 안내는 링크 옆 `?` 팝업에서 표시합니다.
