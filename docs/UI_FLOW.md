# UI 정보 구조와 사용자 흐름

- 문서 상태: v3 구현 기준
- 대상 버전: v3

## 1. UI 목표

사용자는 한 화면에서 다음 순서로 작업합니다.

```text
조회 범위 편집·적용
  → 지도·영향 시설 확인
  → 후속 작업 대상 체크
  → Telegram 발송 또는 PDF 보고서
```

발송과 보고서가 별도 범위를 다시 선택하지 않으며, 체크박스 표가 두 출력물의
유일한 대상 기준입니다.

## 2. 정보 배치

| 정보 | 표시 위치 | 원칙 |
|---|---|---|
| 데이터 상태·최종 갱신 | 제목 아래 상태 표시줄 | KMA 오류를 특보 0건처럼 표시하지 않음 |
| 시설 유형·지도 표시 등급 | 현재 범위 요약과 변경 popover | `조회 범위 적용` 시 한 번에 적용 |
| 위험도 기준 | 사이드바 고급 설정의 큰 편집 작업창 | 전체 특보 행렬, 현재 세션에만 적용 |
| 영향 특보·시설·상 위험 | 필터 아래 요약 3개 | 현재 적용된 범위를 사용 |
| 시설 상세 | 우선순위 패널의 기본 닫힘 영역 | 선택 목록은 유지하고 판정·공개 담당정보를 필요할 때 펼침 |
| 후속 작업 대상 | 지도·상세 아래 기본 닫힘 전체 너비 form | 펼쳐서 대상을 편집하고 버튼 제출 시 두 출력에 동일하게 사용 |
| 특보 원문 | 화면 하단 펼침 영역 | 기본 흐름을 방해하지 않음 |

## 3. 데스크톱 기본 화면

```text
┌──────────────────────────────────────────────────────────────┐
│ K-ECO SAFETY MONITORING                                       │
│ 기상재난 시설 관제        LIVE · 기준 시각 · 정책 버전       │
├──────────────────────────────────────────────────────────────┤
│ 현재 조회 범위 · 전체 시설 유형 / 전체 등급   [조회 범위 변경] │
├──────────────────────────────────────────────────────────────┤
│ 영향 특보 12       │ 영향 시설 32       │ 상 위험 4           │
├────────────────────────────────────┼─────────────────────────────┤
│            통합 지도             │ 점검 우선순위 목록·선택 상세 │
├────────────────────────────────────┴─────────────────────────────┤
│ 후속 작업 대상: [✓] 등급 시설 유형 특보 담당자               │
│ [전체 선택] [전체 해제] [Telegram 발송] [PDF 보고서]       │
├───────────────────────────────────────────────────────────────┤
│ 현재 조회 범위 특보 원문                                      │
└───────────────────────────────────────────────────────────────┘
```

시설 유형 기본 그룹은 대기측정소, 수질측정소, 영농폐기물 수거사업소,
영농폐비닐 재활용시설, 공공하수처리시설, 기타시설입니다. 그룹에 등록되지 않은
신규 시설 유형은 기타시설에 자동 포함됩니다.

## 4. 선택과 출력 규칙

1. 시설 유형과 위험도 필터는 적용된 값과 편집 중인 값을 분리해
   세션 동안 유지합니다.
2. pill을 여러 개 바꾸는 동안 기존 지도와 지표를 유지하고,
   `조회 범위 적용`을 누를 때 한 번에 재계산합니다.
3. 지도에는 적용된 두 필터를 모두 만족하는 시설만 표시합니다.
4. 특보 경계와 특보 원문은 표시 시설에 실제 연결된 특보만 남깁니다.
5. 영향 시설은 후속 작업 표에 기본 전체 체크됩니다.
6. 개별 체크는 즉시 재실행하지 않고 form의 버튼을 누를 때 확정됩니다.
7. 상세 시설 selectbox는 조회에만 사용하며 출력 범위를 변경하지 않습니다.
8. Telegram과 PDF는 체크된 영향 시설 및 해당 시설의 특보만 받습니다.
9. 필터, 모드, KMA 결과 또는 정책이 바뀌면 체크 상태와 생성된 PDF를 새 범위
   기준으로 초기화합니다.
10. 선택 대상이 0개인 작업을 제출하면 안내만 표시하고 작업창을 열지
    않습니다. KMA 조회 실패 시에는 Telegram과 PDF 버튼을 비활성화합니다.
11. 시설 상세 정보와 후속 작업 대상은 PC·모바일 모두 기본으로 접고,
    펼치거나 접는 동작만으로 현재 시설·작업 대상 선택은 변경하지 않습니다.

## 5. 작업창

### Telegram

- 선택 시설 수, 연결 특보 수, 상 위험 수를 먼저 표시합니다.
- 상황 요약 1건 뒤에 `상 → 미판정 → 중 → 하` 상세를 전체 표시합니다.
- 상·미판정이 있을 때만 요약을 일반 알림으로 보내고 상세는 무음으로 보냅니다.
- 유효한 HTTPS 운영 주소가 있으면 시설명을 `facility_id` 딥링크로 표시합니다.
- 사용자가 대상 수를 확인하는 체크박스를 선택해야 발송할 수 있습니다.
- 임시 위험도 기준을 사용하면 메시지에 명시합니다.
- 발송 결과는 현재 화면에만 표시하고 저장하지 않습니다.

### PDF

- Telegram과 동일한 선택 snapshot을 사용합니다.
- 헤더에 조회 범위, 실시간·모의훈련·임시정책 배지, 생성 시각과 정책 버전을
  표시합니다.
- `관제 요약 → 영향시설 우선순위 → 활성 특보` 순으로 구성합니다.
- 남색 헤더, 청록 강조선, KPI 카드와 등급 색상을 업무 식별에만 사용합니다.
- 선택이 달라지면 이전 다운로드 파일을 폐기합니다.

## 6. 위험도 기준 편집

- 정책에 등록된 전체 특보를 행으로, 주의보·경보·중대를 열로 표시합니다.
- 현재 발효 중인 특보를 상단에 놓고 빨간 상태점과 `발효 중`을 표시합니다.
- 미등록 활성 특보도 임시 등급을 지정할 수 있습니다.
- 셀 변경은 재실행하지 않고 `현재 세션에 적용`을 누를 때 전체 위험도를
  한 번 재계산합니다.
- 기본 파일·DB·다른 브라우저에 저장하지 않습니다.

## 7. 예외와 반응형 화면

- API 오류 시 지표는 0이 아닌 `—`로 표시하고 후속 작업을 차단합니다.
- 경계 내장본 사용 시 계산은 계속하되 상태 안내를 표시합니다.
- 미판정 특보는 낮은 위험으로 바꾸지 않고 별도 등급으로 유지합니다.
- 모의훈련은 상태 표시, Telegram과 PDF 제목에 모두 명시합니다.
- 모바일에서는 사이드바를 기본으로 접고 조회 필터를 popover에서
  편집하며, KPI 3개를 한 줄로 표시합니다.
- 모바일 정보 순서는 `상태 → 조회 범위 → KPI → 점검 우선순위 목록 → 지도`입니다.
- 모바일 지도는 430px 높이로 축소하고 기본 잠급하여 한 손가락 페이지
  스크롤을 보장합니다. 지도 내부 버튼으로 이동·확대를 켜고 다시 잠글 수
  있으며, 잠금 상태에서도 마커 탭은 유지합니다.
- 후속 작업 표는 데스크톱에서 핵심 열을 한 눈에 보이고, 모바일에서 축소·스크롤합니다.
- Streamlit 헤더 아래에 본문 여백을 확보해 사이드바 화살표가 제품명을 가리지
  않도록 합니다.

## 8. 접근성과 안전성

- 등급은 색상과 텍스트를 함께 사용합니다.
- 필터와 체크박스는 키보드로 조작할 수 있어야 합니다.
- 최종 선택 대상 수와 연결 특보 수는 Telegram·PDF 작업창에서 확인합니다.
- 담당은 부서·이름/직책만 표시하며 휴대전화는 화면·Telegram·PDF에 노출하지 않습니다.
- Telegram은 미리보기와 최종 확인을 거친 수동 발송만 허용합니다.

## 9. 현장 참고정보

- 선택 시설 20km 내 ITS 고속도로·국도 CCTV를 직선거리 순으로 최대 5개 표시합니다.
- CCTV 마커를 누르면 중간 말풍선 없이 큰 영상 작업창을 열고
  내장 재생·외부 영상·ITS 지도 링크를 제공합니다.
- ITS가 촬영 방위각을 제공하지 않으므로 방향을 자동 추정하지 않습니다.
  이름·좌표가 일치하는 사람 검증 설정이 있는 CCTV만 지도에 고정 방향
  화살표를 표시하고, 나머지는 `촬영방향 미확인`으로 표시합니다.
- 영상 파일 생성 시각과 ITS 영상 주소 조회 시각을 구분하고, 생성 시각이
  제공되지 않으면 촬영 시각을 확인할 수 없음을 명시합니다.
- CCTV 정보는 최대 1분 캐시하며 작업창의 수동 갱신은 캐시를 우회해
  새 영상 주소를 요청합니다. 재생 중인 영상은 자동으로 교체하지 않습니다.
- 선택 시설 관할의 최근 6시간 재난문자를 최대 5건 원문으로 표시합니다.
- API 미설정·오류·0건을 구분하고 KMA 관제와 후속 작업은 차단하지 않습니다.
- 뉴스는 관할·특보 검색어를 사용한 외부 최신순 링크만 제공합니다.
- CCTV·재난문자·뉴스는 참고용이며 위험도·Telegram·PDF에 반영하지 않습니다.
- Google 뉴스 검색 기준과 참고정보 안내는 링크 옆 `?` 팝업에서 표시합니다.
- 지도 레이어 선택기는 제공하지 않고 기본 지도·특보·시설·CCTV를 항상 표시합니다.
