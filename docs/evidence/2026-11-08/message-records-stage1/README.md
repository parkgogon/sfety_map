운영 배포 검수가 아니며 창작 문자/가짜 외부 제공자로 검수했다.

## 구현과 검증 범위

- 관리자 보호 목록/수동·창작 등록/공식 피드 요청 시 조회/검증 등록/상세/분석 저장/메모/이력.
- 수신지역을 원문·출처와 별도로 저장하고 AI 입력에 보존한다.
- 같은 공식 ID 중복 방지, 내용 변경 시 원본 버전·재검토, 이전 분석 이력 보존.
  더 오래된 조회 결과로 원문을 되돌리지 않으며 내용 변경 중 이전 분석을 새 원문에 저장하지 않는다.
- Firestore 현재 문서와 버전 이력을 한 트랜잭션에 쓰는 어댑터와 버전 충돌 처리.
  저장 실패 시 메모리 대체/성공 표시를 하지 않는다. 메모리 사용은 명시적인 로컬 검수용이다.
- 공식 원본 등록은 유효기간/용도가 있는 서버 서명으로 검증하고, 원문/분석을 브라우저가 임의로 만들어
  공식 저장 경로에 넣지 못하게 한다. 공개 API 피드 조회가 등록/분석/발송을 자동 실행하지 않는다.

검증한 소스/테스트 파일은 [SHA-256 목록](source-hashes.json)에 기록했다.

## 브라우저

[점검 JSON](browser-checks.json), [화면 캡처](desktop.png).

실제 로컬 React/Vite → FastAPI → 메모리 테스트 저장소를 연결했다.
OpenAI/Kakao는 이전 검증에서 저장한 창작 예문 응답을 분석 제공자로 대체해 재생했고,
공식 문자 피드는 별도 가짜 제공자로 대체했다. 운영 공식 API 응답을 새로 조회한 것이 아니다.

1. 창작 예문 등록 → 분석 저장 → 검토 메모/추가 확인 상태 저장.
2. 페이지 새로고침 후 원문·수신지역·메모·분석/시설 링크 7개가 복구됨.
3. 1440/390/360px 가로 넘침 없음.
4. 과거 원본 버전 열람과 현재 분석 복귀.
5. 서명된 가짜 공식 문자를 두 번 등록해도 같은 기록 하나이며 AI가 실행되지 않음.

페이지 오류/예상 밖 요청 **0건**, 새 OpenAI/Kakao 호출 **0건**, 실제 발송 **0건**이다.
7개소는 이전 창작 산업단지 예문의 참고 조회 재생값이며 피해/현장 확인 실적이 아니다.
모바일은 크기 에뮬레이션으로 실제 기기 검수가 아니다.
