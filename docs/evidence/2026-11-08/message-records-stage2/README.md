  대피 목적지·참고 장소·해제 구간은 기준점으로 선택할 수 없다.

  별도 출처·확인 근거·명시적 확인과 함께 저장하며 원문/AI 분석을 덮어쓰지 않는다.

  20개소 단위 페이지와 전체 시설 검색을 제공하고 반경 밖 시설에는 개별 추가 사유를 요구한다.
- 시설 ID/거리/이름/주소는 서버가 재계산해 저장한다. 담당자/연락처는 응답·지도·저장 선정에 포함하지 않는다.
- 기준점/반경/시설 자료/원문/분석 변경으로 이전 선정을 재사용하지 않으며 버전 충돌을 검사한다.
  이전 선정은 원본 버전 이력에 보존해 화면에서 읽기 전용으로 확인한다.
- 같은 기준점을 재확인해도 기존 선정을 지우지 않는다. 다른 장소의 선정과 섞거나 자동 선택하지 않는다.
- 조회 기준점/시설 선정으로 AI를 다시 호출하지 않으며 위험도·피해·현장 확인 완료로 해석하지 않는다.

## 브라우저와 한계
