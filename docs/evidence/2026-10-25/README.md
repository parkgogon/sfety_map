React 215개·일반 빌드와 앞선 별도 시안 TypeScript/빌드도 통과했다. PDF를 실제 생성·렌더하고 화면과 연속 프레임을 직접 봤다.
초기 UI/보고서 브라우저는 로컬 자료·가짜 SDK였다. 최종 통합은 실제 SDK/타일·로컬 수정 앱/API를 사용한다.
모바일은 모두 viewport 에뮬레이션이다.
초기 기상 시안은 합성 입력·자체 개략도다. 이후 혼합형 구현은 실제 SDK·타일과 합성 입력으로 검수했다.
보고서 시안은 실제 SDK·타일/CSV와 명시한 합성 시설을 사용했다. 채택안을 기존 API에 연결했으며
마지막 통합 검수는 실제 CSV를 쓴 로컬 1 CPU/1GiB API다. 운영 API·새 배포나 실제 휴대폰 검수로 표시하지 않는다.
새 API는 로컬에서만 호출했다. 운영 dispatch·Worker·발송 시험, main push·배포는 하지 않았다.
