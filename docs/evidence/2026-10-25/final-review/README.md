## 결론과 보완

**재현된 결함 1건을 수정했고, 현재 확인된 미해결 코드 차단 사항은 없다.**

- **P2 · PDF 계산 슬롯 대기 중 취소가 계산까지 이어지던 문제.** 다른 PDF가 계산 슬롯을 점유할 때
  두 번째 요청을 취소해도 worker thread의 동기 대기가 계속되고, 첫 계산이 끝나면 취소한 PDF도 계산했다.
  인계 커밋의 generator 코드를 그대로 로드한 [수정 전 회귀 검사](regression-before.log)가 실패했다.
  작업 파일을 이전 버전으로 돌리거나 운영 API를 호출한 검사가 아니다.
- 슬롯 대기를 비동기로 옮겨 대기 중 취소 시 계산을 시작하지 않고 요청 슬롯을 반환한다.
  10초 대기 제한·요청 3건/PDF 1건 한도는 유지한다. 이미 계산 중인 스레드는 끝까지 정리한다.
  대기 취소 후 렌더 호출 없음·다음 생성 복구, 대기 시간 초과 후 슬롯 복구를 추가 검증했다.
- 기상 검토 문서에 남은 “현재 보고서는 개략도만 제공” 설명을 실제 지도 포함 구현 상태로 수정했다.
