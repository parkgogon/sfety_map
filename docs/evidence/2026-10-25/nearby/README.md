## 미검증·제한

관리자 인증·전파·발송·Worker 시험 경로는 호출하지 않았다. localhost 외 요청은 검수 브라우저에서 차단했다.

`VITE_KAKAO_MAP_APP_KEY=local-browser-fixture`를 사용했고, 최종 일반 빌드에는 넣지 않았다.
