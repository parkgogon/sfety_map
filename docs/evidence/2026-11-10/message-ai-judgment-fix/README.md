## 보완한 동작

- 모델이 대피 목적지·해제 구간·미조회 장소를 전파 근거로 제출하면 기존 서버 기준의 오류를 돌려주고, 남은 응답 안에서 재판단·정정하게 한다.
- 사고/통제인데 일반 예방으로 분류해 기록만 하려는 모순도 같은 검증을 공유한다. 지역/업무 관련성이 미상이면 확인 필요로 남긴다.
- 동일 도구/인자 결과를 재사용한다. 최대 6응답 중 마지막 2응답은 최종 제출/정정용이다. 오류는 필드 경로·원문 인용·시각·역할별로 구체적으로 안내한다.
- 따옴표를 문자열 값에 덧붙이는 인용 오류, 발행 시각을 발생 시각으로 복사하는 오류를 구분해 정정한다. 명확한 당일 24시제 해제 시각을 누락하면 보완을 요구하며, 날짜가 모호하거나 발행 시각 미상일 때 임의로 채우지 않는다.
- 본문 광역지역을 유지하고 발신기관의 구역만으로 산/도로 소재지를 좁히지 않는다. 본문이 명시한 하위 지역 제한은 그대로 검증한다. 실제 Kakao의 교량,다리 종류 표기도 지원한다.
- 새 엄격한 제출 도구는 판단을 필수로 받는다. 이전 저장 분석은 계속 읽을 수 있고 근거가 부족하면 기존 화면/서버에서 확인 필요로 남긴다.
