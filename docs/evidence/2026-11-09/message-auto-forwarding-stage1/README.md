## 재현과 한계

전체 서버 검사는 공통 실행기, 화면 검사는 `field_web`의 `npm test`/`npm run build`로 수행했다.
이 환경의 bubblewrap 안에서는 ASGI TestClient의 이벤트 루프가 멈춰 기본 실행을 중단했다.
외부 통신 차단 장치를 유지한 같은 검사를 bubblewrap 밖에서 수행해 통과했다. 외부 API를 허용해 해결한 것이 아니다.

브라우저는 빌드 후 `test_server.py`를 별도 프로세스로 시작하고 `check_browser.py`를 실행한다.
서버는 loopback만 listen하고 NetworkGuard로 외부 호출을 차단한다. 브라우저도 로컬 외 요청을 차단한다.
지도는 로컬 가짜 SDK로, 실제 Kakao 타일/실기기 터치 검수가 아니다. 직원 링크는 공개 지도 경로 형식까지 검증했다.

실제 모델의 문맥 판단 품질·추가 출력 토큰 비용은 측정하지 않았다. 자동전파 작업 저장/중단 복구·중복 전송 방지·새 수집/비용 정책·
AI 실패 시 긴급 원문 대체·Telegram 결과/재시도·실제 수신자 검수는 후속 단계다.
`notify_ready`는 미발송 추천 결과이고 모든 응답에 `phase=preview`, `dispatch_enabled=false`를 표시한다.
기존 수집/AI 건수 상한·키·예약·기상 기준 상태를 변경하지 않았다.
