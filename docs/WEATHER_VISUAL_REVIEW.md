# 기상 표현 시안 검토 — 혼합형 채택

기능 브랜치의 현장·관제 공통 레이어에 혼합형을 적용했다. 운영 배포는 하지 않았다. UI 정리와 주변 시설 PDF도 별도 단계로 구현·검증했다.
2026-10-25 사용자 선택: **③ 혼합형 — 바람 A, 기온·강수 B**. 아래 사양으로 공통 레이어 구현을 진행한다.

## 채택한 구현 결과

[실제 SDK 검수·화면·영상](evidence/2026-10-25/weather-mixed/README.md)을 확인한다.
수정 빌드와 고정 시설·합성 기상 입력을 등록된 앱 원점에서 검수용 응답으로 제공하고,
Kakao SDK·타일은 실제 네트워크로 읽었다. 운영 변경/운영 새 버전 검증은 아니다. 모바일은 viewport·DPR 에뮬레이션이다.

## 비교안

| 종류 | A — 현재 표현 다듬기 | B — 지도 가독성 중심 |
|---|---|---|
| 바람 | 현재 색면, 짧은 흐름선의 대비·꼬리와 약풍 움직임 개선 | 더 약한 색면, 적은 수의 긴 흐름선 |
| 기온·강수 | 현재 색상, 색면 농도를 소폭 낮춤 | 더 약한 색면, 드문 수치 표기 |
| 이동·줌 | 기존 그림을 배경과 함께 변환 | 동일 |

현재 안은 앱의 실제 색상 토큰·색면·바람 입자 렌더러를 가져온다. A/B 소스는 개발 폴더에만 있다.
긴 입자 설명은 시안에서 제외했다. 비교 조절값은 운영 설정에 추가하지 않는다.
프리뷰의 비교 조건을 펼치면 시설 카드 배치 예시도 켜 볼 수 있다. 실제 시설 카드와는 구분한 합성 예시다.

## 자료와 검증 범위

**모든 기상 입력은 합성이다. 실제 관측값을 사용한 검증이 아니다.** 무풍 0, 약풍 0.5,
보통 4, 강풍 15m/s에 공간 변화가 있는 u/v 격자를 사용한다. 기온·강수도 같은 고정 격자 분포다.
배경은 대구 도심을 떠올리기 위한 자체 개략도다. 실제 도로 위치·지리 정확도나 실제 Kakao 화면이 아니다.
현재 안의 줌 숨김/재표시도 SDK 이벤트를 모사한다. A/B의 매끄러운 변환은 후보 동작이며,
실제 SDK의 재투영·성능이나 현장·관제 정합을 통과했다는 뜻이 아니다.
모바일은 viewport 에뮬레이션이며 실기기가 아니다.

직접 브라우저 조작·연속 프레임·생성 영상과 수치 기록은 [증빙](evidence/2026-10-25/weather/README.md)에 있다.

## 시안 비교에 사용한 후보값

기존 제안값은 확정 사양이 아니다. 아래는 이번 시안의 초기값이며 전부 검토 후 변경할 수 있다.
프리뷰 600×500 좌표 기준으로 화면 배율에 따라 시각적 길이·속도가 변한다.

| 항목 | 현재 | A 후보 | B 후보 |
|---|---|---|---|
| 풍속 색면 alpha | 0.14 | 0.14 | 0.049 |
| 기온/강수 alpha | 0.24 / 0.28 | 0.216 / 0.252 | 0.108 / 0.126 |
| 흐름 수 | 기존 면적 계산 | 135 | 95 |
| 시각적 흐름 속도(px/s) | 기존 렌더러 | 9 + 6√풍속 | 11 + 7√풍속 |
| 꼬리 길이(px) | 기존 누적·감쇠 | 12 + 4√풍속 | 18 + 5√풍속 |
| 숫자 | 없음 | 없음 | 격자 4곳 |

풍속 0에는 흐름선을 그리지 않는다. 위 속도는 약풍 가시성을 위한 표현값이며 관측 풍속을 변경한 값이 아니다.
모든 안은 같은 u/v와 값·색상 범례를 사용한다. 움직임 줄이기는 정적 표시로 바뀌고 자동 비교 재생을 끈다.

## 사용자 검토 후 기록할 사항

바람·기온·강수 각각 **현재 유지 / A / B / 수정 후 재검토**를 정한다. 검토 기준:

- 설명 없이 흐름과 방향이 보이는가. 약풍이 보이며 무풍을 강한 흐름으로 읽지 않는가.
- 이동·줌의 전환이 자연스럽고 도로·지명·시설을 함께 읽을 수 있는가.
- 모바일의 숫자·범례·시설 정보가 가리지 않는가.

검토 결과: **③ 혼합형 채택**. 바람 A, 기온·강수 B를 구현한다. 운영 배포는 별도 승인 범위다.

## 채택한 표현 사양

- 바람: 기존 풍속 색면 alpha 0.14, 중립 청록색 흐름선. 시각적 속도 `9 + 6√풍속` CSS px/s,
  꼬리 `12 + 4√풍속` px. 0m/s에서는 이동·선 모두 없다. 약풍에 최소 흐름을 주되 관측 풍속·방향은 바꾸지 않는다.
  흰 외곽 3.2px, 청록 선 1.5px, 꼬리 그라데이션·수명 감쇠. 기준 면적 600×500당 약 135개이며
  화면 면적에 비례하고 80~600개로 제한한다. 긴 입자 설명은 범례에서 제거한다.
- 기온·강수: 기존 값·색상 범례 유지. 색면 alpha 0.108 / 0.126. 실제 격자값을 최대 4곳에 표시하며
  간격·화면 가장자리·시설 마커·범례·시설 카드와의 겹침을 피한다. 표시할 유효 자료가 없는 곳에는 숫자를 만들지 않는다.
- 이동·확대: 기존 그림을 투영 좌표의 변환과 함께 움직인 뒤 같은 자료로 재투영한다.
  줌 시작 시 숨기지 않는다. 지도 조작으로 기상 API를 다시 호출하지 않는다.
- 현장·관제 공통 적용. 지연·자료 없음·오류·모의훈련 구분과 움직임 줄이기를 유지한다.
- 실제 SDK 조작·연속 프레임·모바일 viewport/DPR2 검수를 완료했다. 스마트폰 실기기·터치 성능은 미검증이다.

보고서에 대한 추가 의견: 사용자는 도로·지명이 없는 개략도가 지나치게 단순하다고 지적했다.
현재 PDF는 의도적으로 개략도만 담는다. 도로 지도 포함형은 출력 가능한 자료·서비스 검토가 필요하며,
지도 배경을 구현했거나 출력 가능성을 검증했다고 표시하지 않는다.
