# 재난문자 간단 검토 사용 안내

이 안내는 간소화 1·2단계의 제한 운영 기준이다. 현재 배포 상태와 검수 결과는 [운영 기록](HANDOFF.md)을 따른다.

## 문자는 어떻게 들어오나요?

서버가 **15분마다 행정안전부 공개 API**를 확인한다. 대구·경북·부산·울산·경남 수신 또는 전국 대상 문자를 모아 저장하고 AI가 검토안을 준비한다.
휴대폰에 수신된 문자를 직접 가져오는 방식은 아니며, 브라우저를 닫아도 서버의 예약 실행은 이어진다.
배포 후 최초 수집 시작 시각 이후의 문자부터 쌓이므로 처음에는 공식 문자 목록이 비어 있을 수 있다.

관리자는 대기함에 준비된 상황을 열어 검토하면 된다. 화면에서 수집 지연/실패·마지막 정상 조회·분석 대기·오늘 한도를 확인한다.
공식 조회는 최근 24시간 450회, AI 분석 시작은 한국 날짜 하루 20건을 수동/자동으로 함께 사용한다.
한도에 걸린 건은 대기하고, 실패했거나 오래 기다린 건은 자동 재분석하지 않으므로 기록을 열어 확인한다.
15분은 조회 간격이며 실제 문자 발송부터 화면에 보일 때까지의 지연을 보장하는 수치는 아니다. [연결·운영 기준](MESSAGE_AUTOMATION.md).

필요하면 `문자 붙여넣기`로 공개 원문을 추가하거나 `예문으로 시연`을 선택한다.
원문만으로 등록·분석을 시작할 수 있다. 출처·발행 시각·수신지역은 알 때 추가한다.
발행 시각을 모르면 비워두며 입력 시각을 발행 시각으로 사용하지 않는다.
창작 시연 기록은 공식 재난이나 업무 실적으로 세지 않는다.

## 한 건을 검토하려면?

1. 대기함에서 분석된 상황을 연다. 새 문자는 `등록하고 검토안 준비`로 분석한다.
2. 요약·추천 위치·확인 대상 시설·안내 초안을 함께 읽는다.
3. 그대로 사용할 수 있으면 `이 내용으로 검토 완료`를 누른다.
   지도 기준과 시설 선정을 각각 저장하거나 정상 건에 사유를 타이핑할 필요가 없다.
4. 전달할 필요가 있으면 저장된 `안내문 복사`를 눌러 기존 보고·전달에 사용한다.

산업단지 대표점처럼 실제 발생 지점과 다를 수 있는 경우에만 참고 조회 기준 확인을 추가로 요청한다.
위치·거리·대상 시설·추가 안내를 바꾸려면 `내용 수정`을 연다.
정보가 부족하거나 시설 자료를 읽지 못하면 `보류`한다. 수정 중인 내용도 미승인 작업본으로 남고 다시 열어 이어갈 수 있다.
오래된 수정 내용 때문에 추천안을 준비하지 못하면 `수정 내용 초기화`로 새 추천안을 시작한다.
서버에 보류한 작업본은 새로 저장하기 전까지 유지된다.
예방 안내는 추가 대상 없이 기록할 수 있으나 관리자가 명시적으로 검토를 마쳐야 완료된다.

## 완료한 뒤 다시 바꿔야 한다면?

`내용 보완·다시 검토`를 누른다. 이전 완료·초안은 이력에 보존한다.
자료나 후속 근거가 바뀌면 이전 초안 복사를 막고 재검토를 안내한다.
기존 자세한 위치/시설 기록·이력·후속 연결 관리는 `상세 관리 열기`에서 확인한다.

추천 거리와 시설은 업무 확인을 돕는 참고자료다.
내부 검토 완료는 현장 확인·재난 종료·시설 안전·실제 발송을 뜻하지 않는다.
