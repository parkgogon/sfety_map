# 기상재난 시설 관제 간편 사용 안내

내부 시험 사용자를 위한 간단한 안내입니다. 전달받은 Streamlit 링크를 스마트폰이나 PC에서 열어 사용합니다.

화면 상단에는 `현장 지도`, `중앙 관제`, `설정` 세 메뉴가 항상 표시됩니다.

## 1. 시설 담당자: 현장 지도

- 시설명·주소를 검색하거나 지도 마커를 누릅니다.
- 상단 `기상청 특보 ↗`를 누르면 기상청 공식 특보 발효현황을 새 탭에서
  함께 확인할 수 있습니다. 모의훈련 중에도 이 링크는 실제 공식 자료입니다.
- 지도 팝업과 아래 선택 시설 카드에서 등급, 영향 특보, 권장 행동을 확인합니다.
- 필요할 때 `현장 참고정보 불러오기`를 눌러 현재 기상·재난문자·CCTV를 조회합니다.
- 스마트폰에서는 지도가 기본 조작 가능하며 `페이지 스크롤 우선`으로 전환할 수 있습니다.

## 2. 중앙관제 담당자: 현재 상황 확인

- 상단에서 `실시간 · KMA 정상`과 기준 시각을 확인합니다.
- `영향 특보`, `영향 시설`, `상 위험` 숫자로 현재 상황을 빠르게 파악합니다.
- 필요한 경우 `조회 범위 변경`에서 시설 유형이나 위험도 등급을 선택합니다.

## 3. 점검할 시설 확인

- 중앙 관제의 기본 `운영 상황`에서 시스템 상태와 현재 우선순위를 봅니다.
- 상세 분석이 필요하면 `대상 분석·전파`로 이동합니다.
- `점검 우선순위 목록`에서 시설을 선택합니다.
- `시설 상세 정보`를 펼치면 판정 근거, 권장 행동, 담당, 주소를 볼 수 있습니다.
- 심층 현장정보는 `현장 지도에서 상세 확인`으로 이동해 확인합니다.

## 4. 중앙관제 지도 사용

- 스마트폰에서는 한 손가락으로 페이지를 스크롤합니다.
- 지도를 이동하거나 확대하려면 지도 안의 `지도 조작 켜기`를 누릅니다.
- 시설 마커와 특보 구역을 함께 확인합니다.

## 5. 후속 작업

- `후속 작업 대상`을 펼치고 필요한 시설만 체크합니다.
- 같은 체크 결과로 시설담당자 그룹 수동 전파나 PDF 보고서를 만들 수 있습니다.
- 수동 전파는 `재공지·정정·추가안내·훈련` 용도만 사용합니다. 자동 특보의
  최초 발효·격상·해제 알림은 별도 작업자가 처리합니다.
- **수동 전파는 실제 시설담당자 그룹에 게시되므로 최종 확인 후 실행합니다.**
- 자동·수동 결과는 `실적·이력`에서 따로 확인합니다.

## 6. 설정

- 위험도 기준은 현재 브라우저 세션에서만 임시로 변경할 수 있습니다.
- 변경한 기준은 현장 지도·중앙 관제·Telegram·PDF에 함께 반영됩니다.
- 새 브라우저 세션은 기본 기준으로 시작합니다.

## 사용 중 문제가 생기면

화면 캡처와 함께 `발생 시각`, `선택한 시설`, `사용 기기(스마트폰/PC)`를 전달해 주세요.
