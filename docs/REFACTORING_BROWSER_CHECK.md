# 구조 개선 브라우저 검수

기준: 2026-10-24, 로컬 프로덕션 빌드, Chromium headless.
3단계 화면 분리 후와 4단계 지도 분리 후 동일한 검수를 각각 통과했다.
로컬 정적 서버만 실행했고 API·지도 SDK는 검수용 가짜 구현을 주입했다.
모든 `/api/`·`/internal/` 요청은 브라우저에서 가짜 응답으로 종료하고 외부 목적지는 차단했다.
운영 API·Worker·Telegram·SMS·Firestore는 호출하지 않았다.

| 화면 크기 | 현장 `/` | 관제 `/control` | 설정 `/settings` |
|---|---|---|---|
| 390×844 | 렌더링·가로 넘침 없음 | 동일 | 동일 |
| 430×932 | 동일 | 동일 | 동일 |
| 700×360 | 동일 | 동일 | 동일 |
| 1440×900 | 동일 | 동일 | 동일 |

- 현장 지도에서 모바일→PC로 크기 전환 시 지도 인스턴스 생성 횟수가 늘지 않았다.
- 관제에서 선택 해제→실적 이력→대상 분석 복귀 후 0개 선택이 유지됐다.
- 전체 3개 시설 선택→전파 모달→확인→가짜 API 전송 1회→성공 처리를 확인했다.
  전송 대상 ID는 가짜 시설 3개와 일치했다. 실제 전송은 없다.
- 브라우저 페이지 오류 0건, 외부 페이지 요청 0건.
- 미검증: 실제 Kakao 타일·지오코딩·운영 기상, 실기기 키보드·safe-area·OS 글자 확대.
  지도 오버레이 동작은 SDK 가짜 구현을 쓰는 자동 회귀 검증과 함께 판단한다.
